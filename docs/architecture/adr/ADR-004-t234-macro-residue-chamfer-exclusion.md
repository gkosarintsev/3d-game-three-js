# ADR-004: T23.4 macro residue — «срезанные углы» исключены (замена: «косые районы»)

- Статус: **accepted** (T23.4, 2026-11-20)
- Дата: 2026-11-20
- Автор: agent (`agent/plan23-t234-macro`)
- Связано: `.ai/plans/23-plan21-literal-closure.md` (T23.4), `docs/level_generation_rules_claude.md` §10.1 (макро-приёмы: «срезанные углы»), `.ai/state/citygen-procedural-rules.md`, ADR-003.

## Контекст

План 23 (T23.4) требует реализовать macro-chaos residue, в том числе: «срезанные углы» (chamfered corners) — **если найдётся честная axis-aligned IR-реализация — либо осознанно исключены с ADR-заменой на «косые районы»**.

Текущий IR/геометрический контракт зданий и кварталов axis-aligned/rect-based: `buildings[].footprint`/`walls`/`bounds` и производные планы/коллизии/навигация опираются на осевые прямоугольники (локальные оси домов, `toWorld`/растеризация по rect-ячейкам, резы/примыкания). Срез угла здания/квартала означает диагональную грань/полигональный контур, не представимый честно в axis-aligned IR без рассинхронизации «картинка ≠ коллизия ≠ навигация/опора».

## Решение

1. **«Срезанные углы» в T23.4 осознанно исключены** из реализации: честной axis-aligned IR-реализации в текущей схеме/движке нет.
2. **ADR-замена:** концепт **«косые районы»** (oblique districts / диагонально ориентированные или полигональные кварталы как отдельный IR/схемный пласт). Это требует отдельного проектирования схемы, коллизий, навигации и компиляции (не укладывается в T23.4 без нарушения контрактов/инвариантов).
3. Диагональная «прорезь улицы» и «площадь-клапан» (остальные пункты T23.4) реализуются честно в рамках текущих IR/стадий (stage-2 + детерминированная манифестация), без попыток имитировать chamfer через некорректные axis-aligned аппроксимации.

## Последствия

- §10.1 macro-приём «срезанные углы» остаётся **не реализован** намеренно (не silent deviation), с явной заменой на будущий концепт «косые районы».
- Любая будущая реализация chamfer/косых кварталов — отдельная задача/ADR с расширением IR/схемы и пересмотром контрактов геометрии/навигации.
- Прочие пункты T23.4 (диагональная прорезь, площадь-клапан) не зависят от этого решения.
