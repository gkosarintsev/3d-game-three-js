# Level Editor (MVP)

Локальный браузерный редактор CityForge source-уровней (`src/levels/level-NN.json`).
Основан на визуализаторе (`tools/level-visualizer.html`), но редактирует **черновик исходных данных**, а не скомпилированные `chunk-*.l14b`.

## Запуск

Обычный просмотр (без записи в файлы):

```bash
python -m http.server 8124
# открыть http://localhost:8124/tools/level-editor.html?level=19
```

С локальным endpoint-ом записи:

```bash
node tools/level-editor-server.mjs --write --port=8125
# открыть http://localhost:8125/tools/level-editor.html?level=19
```

Без `--write` endpoint возвращает `403` (но `?dryRun=1` работает для проверки). Путь всегда ограничен `src/levels/level-<NN>.json`; сторонние файлы перезаписать нельзя.

## Что умеет MVP

- загрузка `kind: cityforge` / v3 / v4 с существующим `src/levels/level-NN.json`;
- режим только просмотр + редактирование:
  - выбор узла/сегмента/элемента кликом;
  - создание узла (`+ Узел`);
  - создание сегмента двумя кликами с пресетом (`Земля`, `Мост`, `Подъём`, `Расширение`, `Левый/Правый съезд`);
  - создание дуги (`+ Дуга`);
  - удаление выбранного объекта (`Delete` или `Удалить`);
  - перетаскивание выбранного объекта в режиме `Двигать`;
  - кнопка **«Скруглить стык»** — кликнуть по двум дорогам, встречающимся в общем узле (узлы с одинаковыми/близкими координатами в пределах 1.5 м тоже считаются стыком); под нижней дорогой будет выбрана дорога, отличная от первой при клике; редактор подрежет прямые и вставит дугу радиуса `R` (поле рядом с snap); работает на любых углах, не только 90°;
- инспектор: `id/type/layer`, параметры `plate` или `arc` (включая `rails`); при вводе значения preview обновляется сразу, а шаг фиксируется в undo по blur/Enter;
- блок **«Курсор»** под инспектором показывает мировые координаты `x/y/z`, соответствующие указателю над картой;
- undo/redo (`Ctrl+Z` / `Ctrl+Shift+Z`);
- `Validate` — быстрая проверка черновика;
- `Download JSON` — скачивание отредактированного `level-NN.json`.

## Параметр snap

Размер сетки **snap** влияет только на фиксированные операции:

- `+ Узел` — если рядом уже есть узел, выбирает существующий, а не создаёт дубликат; новый id всегда уникален;
- `+ Сегмент` / `+ Дуга` — вторая точка снапится к сетке и к ближайшему существующему узлу; сегмент короче 1 м не создаётся (двойной клик отменяет создание);
- drag элементов/концов — во время движения preview плавный, а финальное положение снапится к сетке на отпускании.

Поля инспектора принимают любое число и не снапятся; `snap = 0` отключает привязку.

## Перетаскивание объектов и концов

- В `top`-виде drag работает для узлов, целых элементов и их концов: синий шарик — начало элемента (A), оранжевый — конец (B).
- Клик/drag с пустой области двигает карту; drag по объекту/концу двигает объект.
- Для `plate` конечные метки меняют `A/B`, из которых пересчитываются `x`, `z`, `yaw`, `length`, `y`, `rise`.
- Для `arc` drag конца меняет угол и радиус этой дуги; `y0`/`y1` меняются через поля.
- В инспекторе есть отдельный блок **«Концы элемента»** с полями `A x/z/y`, `B x/z/y`; изменения применяются live и откатываются через Undo.

## Зачем Undo / Redo / Revert

- **Undo** (`Ctrl+Z`) — отменить последнее изменение черновика.
- **Redo** (`Ctrl+Shift+Z`) — вернуть то, что вы отменили через Undo; доступно только после Undo и очищается новым изменением.
- **Revert** — не «шаг назад», а полный сброс черновика к `src/levels/level-NN.json`, который был загружен при открытии. Используйте, если хотите отменить вообще все несохранённые правки; для одной ошибки используйте Undo.

## Что делать после редактирования

**Вариант A — через endpoint (рекомендуется):**

1. Запустите редактор как `node tools/level-editor-server.mjs --write` (см. «Запуск»).
2. Правьте черновик → `Save JSON`.
3. Либо нажмите `Build + Check`, либо включите чекбокс `build+check` рядом с `Save JSON` — тогда пересборка и проверка выполнятся автоматически после успешного сохранения.

Выполняемые команды:

```bash
node tools/build-level.mjs src/levels/level-NN.json
node tools/build-level.mjs src/levels/level-NN.json --check
```

**Вариант B — без записи endpoint-ом:**

1. `Download JSON`.
2. Заменить `src/levels/level-NN.json`.
3. Те же команды пересборки вручную.

## Что умеет MVP (дополнено)

- snap к ближайшим существующим узлам для добавления сегментов/дуг (в дополнение к сетке);
- drag выбранного объекта в `top`-виде: объект тянется под мышью, карта двигается только с пустой области;
- `Download JSON` — скачивание файла через File System Access API (или blob fallback); `Copy JSON` — копия в буфер;
- `Undo`/`Redo` — отменить/вернуть последнее действие; `Revert` — полный откат к исходному source-файлу (с подтверждением).
- удаление узла с подтверждением, если к нему привязаны сегменты;
- `Save JSON` — запись draft в `src/levels/level-NN.json` через `/api/level/<NN>` (только при запуске с `--write`);
- `Build + Check` — пересборка каталога и `--check` через `/api/level/<NN>/rebuild`; чекбокс `build+check` включает это автоматически после успешного `Save JSON`;
- `Download JSON` — скачивание файла;
- `Validate` — проверка перед сборкой.

## Ограничения

- Редактор не пишет прямо в репозиторий: `Download JSON` → ручная замена файла.
- `compiled`-каталог (`src/levels/level-NN/`) не редактируется напрямую.
- Preview — упрощённые примитивы (preview-only), не runtime/Collision; итог нужно проверять игрой/визуализатором.
- Дуги редактируются числовыми полями (`cx/cz/radius/from/to/y`), ручная переташкивка дуги не поддерживается.
- Созданные узлы получают синтетические `id` (`n_<x>_<z>`), сегменты — `road_/bridge_/ramp_/taper_<n>`; `id` уникальность проверяется в `Validate`.
